## 职鲸是什么？

职鲸是一款由用户自带 LLM API 驱动的浏览器求职 Agent。它围绕同一个岗位档案，把职位读取、JD解读、简历证据匹配、个性化招呼语、面试训练、Offer分析、谈薪签约、入职准备和试用期管理连接成完整流程。

职鲸坚持两个原则：

- 不虚构候选人的经历、项目和数据。
- 不绕过招聘平台风控，不进行无人确认的自动群发。

## 核心能力

| 模块 | 能做什么 |
|---|---|
| 岗位作战报告 | 解读JD显性与隐性要求，区分事实、推断、风险和待确认问题 |
| 简历匹配 | 将JD要求与母版简历中的真实证据逐项对应 |
| HR招呼语 | 为不同岗位生成三种自然、具体、可直接调整的话术 |
| 一岗一简历 | 仅基于已有事实优化表达，并导出整洁简历 |
| 面试训练 | 单轮5题，或HR初面到负责人终面的20题全流程训练 |
| Offer闭环 | Offer比较、谈薪、签约、背调、入职和试用期跟进 |
| 报告与历史 | 每次生成保留独立版本，支持彩色报告和原文导出 |

## 三分钟开始使用

1. 在最新 Release 下载 `职鲸-V*-正式版.zip` 并解压。
2. 打开 `edge://extensions` 或 `chrome://extensions`。
3. 开启“开发人员模式”，选择“加载已解压的扩展程序”。
4. 在职鲸“AI配置”中填写你自己的模型API。
5. 上传母版简历，打开招聘岗位页面并点击“读取当前页面”。
6. 保存机会后启动完整岗位分析。

> 推荐先阅读[完整在线新手教程](https://z177010203.github.io/zhi-jing/)。

## 数据与隐私

- 简历、照片、岗位档案和报告默认保存在浏览器本地。
- API Key由用户自行提供，职鲸不提供或转售模型额度。
- 只有用户主动分析时，JD和简历文本才会发送至所选模型服务商。
- 照片默认不发送给无视觉能力的模型。
- 未经用户确认，职鲸不会自动投递或发送招聘消息。
